# 五福改进版 v5 → AQ-Platform 移植回测报告（2026-11-16）

## 移植说明（聚宽 → RQAlpha）

用户提供的是聚宽（JoinQuant）平台策略，无法在本项目直接运行，已做如下适配：

| 维度 | 聚宽原版 | 本项目移植版 |
|---|---|---|
| API | `initialize` / `handle_bar` / `run_daily` / `g.*` / `log` | `init(context)` / `handle_bar(context, bar_dict)` / `context.*` |
| 数据 | `get_price` / `attribute_history`（DataFrame） | `history_bars`（numpy ndarray） |
| 标的 | 100+ ETF 动态池（518880/513100 等） | 2 只 A 股（000001.XSHE / 600519.XSHG）——本项目 bundle 暂无 ETF 合约 |
| 调度 | 09:00/09:20/09:31/15:30/15:40 多时点 | 整合进单一 `handle_bar`（日线收盘决策并执行） |
| 成本 | 聚宽默认 | 平台强制保守默认：滑点 0.2%、佣金万八、印花税千一、T+1、涨跌停/成交量限制 |
| 未来函数 | 聚宽 `avoid_future_data` | 平台 AST 硬校验，禁止 `shift(-n)` / 墙钟 / 外部数据 |

**核心逻辑保留**：多维超参动量共识选股（12 组 lookback×r2×ma）、市场状态机（走弱/牛市/强防）、多层风控（硬止损/成本保护/移动止损/MA破位/ATR吊灯/RSI超买）、持仓粘性、近10日回撤强防。

## 分层验证（Layer 4，防过拟合）

- 区间：2021-01-01 ~ 2026-11-15，切分点 2025-02-13（is_ratio=0.7）
- **status = fail**：样本外年化 -7.19%（要求 >0，未通过）；样本外回撤 25.95%（通过）；周转漂移 55.8（通过）
- 样本内年化 -10.61%，样本外 -7.19%：无过拟合特征，但策略本身在该双标的池上不具备正收益能力。

## 根因分析

策略为「ETF 动量轮动」设计，依赖大池子的横截面排序选出相对强势标的；本移植版只有 2 只股票，共识选股退化为二元切换，叠加 0.2% 滑点与 T+1，交易成本与择时噪声主导了收益。要在项目上真正复现该策略，需要：① bundle 加入 ETF 合约与 ETF 数据源；② 更大标的池；③ 与聚宽一致的费率口径（平台当前强制保守默认，不可关闭）。

## 过程中修复的项目 Bug

回测发现 `/api/backtest` 与会话回测路径把 `cash` 放进 `run_config` 用于校验，却未透传给 runner（默认按 100 万跑），导致手续费与 2 万本金严重不匹配。已修复：`/api/backtest`、`_backtest_version`、`run_conversation`、`run_edit_turn` 四处均把 `cash` 显式透传。
