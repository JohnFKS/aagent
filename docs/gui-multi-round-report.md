## 测试中发现并修复的问题

1. **区间越界报错不可读(真实问题,已修)**:R8 最初只显示通用崩溃提示
   ("history_bars 一维 ndarray…"),真实原因(`There is no data between …`)
   藏在 execution_error 字段。已修:`/api/backtest` 对 "There is no data between X and Y"
   模式映射为"回测区间 X ~ Y 无行情数据,请调整起止日期";其它崩溃附带原始错误末行,
   外部 agent 可据此自纠(新增测试 `test_no_data_error_mapped_to_readable_range_hint`)。
2. **测试脚本竞态(非应用问题)**:各 Tab 面板常驻挂载,隐藏面板的残留 error-bar 会让
   全局 `.error-bar` 轮询提前退出。已把轮询作用域限定到当前面板(`.studio-layout` /
   `.conv-result`)后 8/8 通过;截图中 R7 出现的"陈旧 toast"亦由此解释(R4/R5 的
   toast 尚在 6.5s 存活期内)。

## 一致性核对(R1~R4 指标横向对比)

- 不同日期段/标的的 总收益、基准收益、最大回撤、成交笔数 各不相同且与 legend 行一致;
- R2 自基准 sanity check:策略净值 ≤ 买入持有(均线择时有摩擦成本),方向正确;
